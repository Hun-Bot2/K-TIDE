# Paper (draft)

- Format: ACL **Long** paper (8-page body; references, Limitations, Ethics and appendix do not count).
- Target: **NAACL 2027 Student Research Workshop**, archival long paper, deadline 2027-01-11 AoE, double-blind.
  arXiv only after the course instructor's consent. Plan: `docs/research/goals_and_timeline.md`.
- **The paper never mentions the course assignment, its grading, or the instructor's evaluation.**
  The task is described as a Korean domain-specific QA task with fixed inference conditions.
- Framing: a controlled **empirical study** of data construction choices for a small model, not a new method.
  Do not overclaim novelty.

## Writing rules

1. **No numbers without an artifact.** Every number in the paper must come from `runs/` or `docs/progress/`.
   Tables are generated by scripts (to be added under `src/ktide/paper/`), not typed by hand.
2. **Public repository and double-blind review.** Do not link this repository in the submission. The paper text contains aggregate numbers and methods only. Never include
   the instructor's questions, lecture sentences, or model answers verbatim.
3. **Pending work is marked.** `\pending{...}` = depends on experiments not yet run;
   `\todo{...}` = writing work. Both render in color and must be gone before submission.
4. **Citations.** Only add a BibTeX entry after checking the original paper (authors, year, venue,
   claimed result). Unverified candidates stay as comments in `sections/02_related_work.tex`.
5. Abstract, Results and Conclusion are written only after the RQ1/RQ2 experiments.

## Build

The ACL style files (`acl.sty`, `acl_natbib.bst`) are not yet in the repository.
After adding them to `paper/`:

```bash
cd paper && tectonic main.tex
```
