페이지 집계에는 원본 목록에 있는 중복 파일을 포함했다.

| 페이지 유형 | 페이지 | 비율 |
|---|---:|---:|
| 텍스트 중심 후보 | 559 | 36.8% |
| 수식·표 후보 | 528 | 34.8% |
| 정보성 이미지·다이어그램 후보 | 311 | 20.5% |
| 표지·목차 | 38 | 2.5% |
| 장식용 후보 | 0 | 0.0% |
| 미확인 | 82 | 5.4% |

Poppler의 텍스트 레이어와 래스터 이미지 목록을 사용했다. 텍스트 추출률은 전체 페이지 중 추출된 문자나 숫자가 하나 이상인 페이지의 비율이다. 언어는 추출 텍스트의 한글과 영문 문자 비중으로 분류했다. 두 비중이 각각 5% 이상이면 혼합으로 집계했다.

판본 후보는 사본 번호를 뺀 파일명이 같거나, 순서가 일치하는 정규화 텍스트 페이지가 최소 5개이면서 비교 가능한 페이지 수가 더 적은 파일의 50% 이상인 경우다. 개념 출처는 표기가 탐지된 페이지다. 관련 표기는 탐지됐으나 해당 개념의 표기가 탐지되지 않은 파일을 정의·원리 누락 검토 대상으로 표시했다.

일부 PDF에서 Poppler 숫자 형식 경고가 발생했다. 전체 파일에서 PDF 메타데이터와 추출 결과의 페이지 수가 일치했다. 페이지 유형, 판본 후보, 개념의 정의·설명 범위는 수동 검토 전이며, 벡터 다이어그램과 이미지 내 텍스트는 별도 판독이 필요하다.

시각 검토 우선순위는 추출된 문자 수와 래스터 이미지 신호를 기준으로 정했다. 렌더링 표본 6쪽을 직접 확인했으며, 위 페이지 유형 집계는 최초 자동 분류를 유지한다. 표본은 자동 분류의 오류율을 추정할 수 있는 무작위 표본이 아니다.

## 사용자 검토 반영

판단을 요청한 15쪽은 모두 제외로 분류됐다. 기존 라벨을 포함한 제외 28쪽을 반영해 후보 코퍼스를 1,490쪽으로 갱신했다. 후보에는 별도 유지 라벨이 없는 미검토 페이지도 포함된다.
